# Activity 2: Self-Check Notes

1. **What is the difference between `JTextField` and `JTextArea`?**
   `JTextField` is a single-line text input (e.g., username or search query), while `JTextArea` supports multi-line text input (e.g., comments or descriptions).

2. **Why do we put `JRadioButton`s inside a `ButtonGroup`?**
   A `ButtonGroup` enforces mutual exclusion so only one radio button in the group can be selected at a time.

3. **Why does the `JTextArea` need a `JScrollPane`?**
   `JTextArea` does not provide scrollbars on its own; wrapping it in a `JScrollPane` displays scrollbars automatically whenever the text exceeds the visible area.
